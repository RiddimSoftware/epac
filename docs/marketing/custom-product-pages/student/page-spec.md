# Custom Product Page: Students & Educators

**App Store Connect page name:** student-educator
**Target URL slug:** (assigned by ASC after creation)
**Audience:** Students, educators, civics teachers

## Positioning

"Canada's Parliament in plain language — for the classroom and beyond."

Students and educators need Parliament to be approachable, not intimidating. epac presents the real parliamentary record — debates, bills, votes — in a format that reads like a conversation, not a bureaucratic archive.

## How to create in App Store Connect

1. App Store Connect → My Apps → epac → App Store tab → Product Pages
2. Click + to create new custom page
3. Name: "student-educator"
4. Upload the 6 screenshots
5. Add the description and promotional text variants
6. Click Submit
7. Copy the resulting ppid URL parameter for use in education outreach
