# Custom Product Pages

App Store Connect supports up to 35 custom product page URLs per app. Each can have unique screenshots, description, and promotional text targeting a specific audience.

## How to set up a new page

See individual page-spec.md for screenshots and copy.
Setup steps are in each spec under "How to create in App Store Connect."

## Tracking

After a page is live, link it in outreach materials and track impressions + CVR separately in ASC Analytics → Product Pages.
