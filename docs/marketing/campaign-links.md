# App Store Campaign Links Registry

Campaign links are created in App Store Connect → Analytics → Acquisition → Campaign Links.
Each generates a unique URL that attributes installs to that specific channel in ASC Analytics.

## How to create a new link

1. Sign in to App Store Connect at appstoreconnect.apple.com
2. Navigate to: My Apps → epac → Analytics → Acquisition → Campaign Links
3. Click "+" to create a new campaign
4. Enter the campaign name using the slug from this table (e.g. `epac-web-home`)
5. Copy the generated URL
6. Update this file with the URL in the table below

## URL format — ct= attribution parameters (works immediately)

Until formal ASC campaign links are created, use Apple's `ct=` query parameter for basic attribution.
These appear in ASC Analytics → Acquisition → Campaign Links automatically once clicked.

```
https://apps.apple.com/ca/app/epac/id6739397803?ct=SLUG&mt=8
```

Where `SLUG` is the campaign slug from the table above (e.g. `epac-web-home`).

The website already uses `utm_source`, `utm_medium`, and `utm_campaign` parameters.
Add `ct=SLUG&mt=8` to each URL to enable ASC native attribution alongside utm tracking.

### Example — homepage main CTA button (index.html)

Before:
```
https://apps.apple.com/ca/app/epac/id1224459142?utm_source=epac-web&utm_medium=homepage&utm_campaign=organic
```

After (ct= attribution added, canonical ID used):
```
https://apps.apple.com/ca/app/epac/id6739397803?ct=epac-web-home&mt=8&utm_source=epac-web&utm_medium=homepage&utm_campaign=organic
```

### Example — riding page (generated by generate_ridings.py)

Before:
```
https://apps.apple.com/ca/app/epac/id6739397803?utm_source=epac-web&utm_medium=riding-page&utm_content=abbotsford&utm_campaign=organic
```

After:
```
https://apps.apple.com/ca/app/epac/id6739397803?ct=epac-web-riding&mt=8&utm_source=epac-web&utm_medium=riding-page&utm_content=abbotsford&utm_campaign=organic
```
